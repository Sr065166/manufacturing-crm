# Manufacturing CRM

A full-stack MERN Manufacturing CRM Dashboard.

## Features

- User Authentication
- Dashboard Overview
- Employee Management
- CRUD Operations
- MongoDB Database
- Responsive UI

## Tech Stack

Frontend:
- React
- Tailwind CSS
- React Router
- Axios

Backend:
- Node.js
- Express.js
- MongoDB
- JWT Authentication

## Installation

### Backend

```bash
cd server
npm install
node server.js
```

### Frontend

```bash
cd client
npm install
npm run dev
```
